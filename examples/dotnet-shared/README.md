# dotnet-shared

This folder holds shared reference material for the Varlock `.NET` examples. It is not a runnable project and is not part of the automated framework validation set.

Use `.env.schema.reference` as the quick schema cheat sheet for the decorator and value-pattern surface the current `.NET` initiative actually exercises. It is intentionally narrower than the full Varlock schema language so it stays aligned with checked-in example evidence.
